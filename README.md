# Alexis Casique — SDET portfolio

A responsive portfolio built with plain HTML and CSS. No dependencies or build step are required. Background, skills, projects, and public contact details remain marked as pending owner content.

## Site structure

- `index.html`: introduction, testing themes, and project spotlight.
- `about.html`: background, learning journey, and interests placeholders.
- `projects.html`: future case-study space.
- `contact.html`: space for approved public contact details.
- `skills.html`: space for confirmed technical skills and proficiency levels.
- `css/styles.css`: shared styles and mobile layouts.

## Local preview

Open `index.html` directly in a browser. Use the navigation to visit the other pages. No server or installation is needed.

## Editing and review

Edit the HTML files directly. Add only verified skills, projects, and approved public contact information. The site does not currently need JavaScript. Future shared scripts belong in `js/main.js`, and images in `images/`, using relative paths.

Before publishing, review desktop and mobile layouts, keyboard navigation, links, and personal content. Project guidance is in `AGENTS.md`.
